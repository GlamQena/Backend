                          git
* merge to github main branch: 
 1- 'git checkout main' (switch to local branch main) 
 2- 'git merge [branch-name]' (merge with the local branch  work) 
 3- 'git push -u origin main' (push to the remote main branch)

* leave merge commit message in Vim editor:
 1- write the message at the first line in orange 
 2- press 'Esc' to exit the '--insert--' mode
 3- write ':wq' to "write" the message and "quit" the editor
